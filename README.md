A program that writes one word to `/output/entry.txt` for make.fun's "One Word From Grandma" bounty: the single word a grandma would text about AI.

> Chatty

The word is the pet name a warm, slightly baffled grandma would give ChatGPT — not the product's name, but the name she gives it, the way she names the neighbour's dog. She thinks the chatbot is a chatty little person who lives in the phone.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (6 characters, inside the sealed 1–30 gate, exactly one word), validates the gate before writing, and reads the file back to verify it landed byte-identical.
